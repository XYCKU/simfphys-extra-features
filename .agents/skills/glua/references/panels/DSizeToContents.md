# DSizeToContents

**Realm:** Client, Menu  ·  **Members:** 4  ·  **Inherits:** `Panel`

A helper panel that will automatically resize itself to fit all its children using [Panel:SizeToChildren](https://wiki.facepunch.com/gmod/Panel:SizeToChildren).

[wiki page](https://wiki.facepunch.com/gmod/DSizeToContents)

### DSizeToContents:GetSizeX · Client, Menu
`DSizeToContents:GetSizeX() → boolean`

Returns whether the [DSizeToContents](https://wiki.facepunch.com/gmod/DSizeToContents) panel should size to contents horizontally.

**Returns:**
- boolean — Whether the panel should size to contents horizontally.

[wiki](https://wiki.facepunch.com/gmod/DSizeToContents:GetSizeX)
