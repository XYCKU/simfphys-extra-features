# DBubbleContainer

**Realm:** Client  ·  **Members:** 3  ·  **Inherits:** `DPanel`

A transparent gray speech bubble panel made up of a rounded box and point coming from the bottom.

### DBubbleContainer:OpenForPos · Client
`DBubbleContainer:OpenForPos(x: number, y: number, w: number, h: number)`

Sets the speech bubble position and size along with the dialog point position.

**Arguments:**
- `x` (number) — The x position of the dialog point.
- `y` (number) — The y position of the bubble container.
- `w` (number) — The width of the bubble container.
- `h` (number) — The height of the bubble container.

[wiki](https://wiki.facepunch.com/gmod/DBubbleContainer:OpenForPos) · [source](https://github.com/Facepunch/garrysmod/blob/master/garrysmod/lua/vgui/dbubblecontainer.lua#L14-L29)
