# Material

**Realm:** Client  ·  **Members:** 2  ·  **Inherits:** `Button`

Material is a VGUI element that renders a VMT material.

[wiki page](https://wiki.facepunch.com/gmod/Material)

### Material:SetAlpha · Client
`Material:SetAlpha(alpha: number)`

Sets the alpha value of the Material panel.

**Arguments:**
- `alpha` (number) — The alpha value, from 0 to 255.

[wiki](https://wiki.facepunch.com/gmod/Material:SetAlpha)

---

### Material:SetMaterial · Client
`Material:SetMaterial(matname: string)`

Sets the material used by the panel.

**Arguments:**
- `matname` (string) — The file path of the material to set (relative to "garrysmod/materials/").

> **Note:** If the material is not showing up as the correct size, try setting the Material panel's `AutoSize` variable to **false**

[wiki](https://wiki.facepunch.com/gmod/Material:SetMaterial)
