# DProgress

**Realm:** Client, Menu  ·  **Members:** 2  ·  **Inherits:** `Panel`

A progressbar, works with a fraction between 0 and 1 where 0 is 0% and 1 is 100%.

[wiki page](https://wiki.facepunch.com/gmod/DProgress)

### DProgress:GetFraction · Client, Menu
`DProgress:GetFraction() → number`

Returns the progress bar's fraction. 0 is 0% and 1 is 100%.

**Returns:**
- number — Current fraction of the progress bar.

[wiki](https://wiki.facepunch.com/gmod/DProgress:GetFraction)

---

### DProgress:SetFraction · Client, Menu
`DProgress:SetFraction(fraction: number)`

Sets the fraction of the progress bar. 0 is 0% and 1 is 100%.

**Arguments:**
- `fraction` (number) — Fraction of the progress bar.

[wiki](https://wiki.facepunch.com/gmod/DProgress:SetFraction)
