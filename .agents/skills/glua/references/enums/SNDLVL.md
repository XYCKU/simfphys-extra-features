# SNDLVL enumeration

**Realm:** Shared  ·  **Constants:** 30

The sound's attenuation, or how fast it drops away. Enumerations used by [EmitSound](https://wiki.facepunch.com/gmod/Global.EmitSound) and [Entity:EmitSound](https://wiki.facepunch.com/gmod/Entity:EmitSound). Information taken from [soundflags.h in Source SDK 2013](https://github.com/ValveSoftware/source-sdk-2013/blob/0d8dceea4310fde5706b3ce1c70609d72a38efdf/sp/src/public/soundflags.h#L53)

The engine starts running into trouble below 60dB.

[wiki page](https://wiki.facepunch.com/gmod/Enums/SNDLVL)
