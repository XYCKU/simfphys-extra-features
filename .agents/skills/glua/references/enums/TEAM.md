# TEAM enumeration

**Realm:** Shared  ·  **Constants:** 3

Default defined teams in Garry's Mod. This does not include any custom teams created in custom gamemodes. Enumerations to use with [Player:Team](https://wiki.facepunch.com/gmod/Player:Team)

[wiki page](https://wiki.facepunch.com/gmod/Enums/TEAM)

| Constant | Value | Realm | Description |
|---|---|---|---|
| `TEAM_CONNECTING` | `0` | Shared | Connecting team ID, set when player connects to the server |
| `TEAM_SPECTATOR` | `1002` | Shared | Spectator team ID |
| `TEAM_UNASSIGNED` | `1001` | Shared | Unassigned team ID, set right after player connected |
