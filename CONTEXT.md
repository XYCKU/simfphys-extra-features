# Project: Simfphys Extra Features (SEF)

Purpose:
A framework for extending simfphys vehicles without modifying vehicle addons.

Major modules:

- Registry
- Dashboard
- Indicators
- Text indicators
- Features
- Conditions
- Formatters
- Weather providers

Design goals:

- Extensible by third-party addons
- Data-driven configuration
- Minimal per-frame allocations
- No compile step
